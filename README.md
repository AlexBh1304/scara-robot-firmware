# SCARA Robot Firmware

Bare-metal firmware for a 3-axis SCARA robot arm, written in C for STM32 microcontrollers. The project is developed on an **STM32F103** and is being **ported to the STM32F411**, using a small hardware abstraction layer so the robot logic does not depend on the chip.

> **Status: work in progress.** Expected completion: **December 2026**. See the [status table](#status) and [roadmap](#roadmap) for what works today.

## Goals

- Drive the robot joints with precisely timed step pulses generated by hardware timers (no bit-banging).
- Close the position loop on each joint with an AS5600 magnetic (Hall effect) encoder.
- Keep the robot logic (kinematics, motion planning) independent from the MCU, so the same code runs on the F103 and the F411.
- Write the peripheral drivers from scratch (register level) to understand what the hardware is actually doing.
- Add a teach pendant to jog the robot and record positions.

## Example: step pulse train

`examples/stm32f103/step_pulse_train/` generates a fixed number of pulses on PA8 using TIM1 in PWM mode. An update interrupt counts the pulses, applies a simple linear ramp to the period at the start, and stops the timer after the last pulse.

Things I learned while building it:

- Forcing an update event (`UG`) also sets the update flag, which fires an interrupt as soon as the interrupt is enabled. The flag must be cleared before enabling the interrupt.
- Variables shared between an ISR and `main` must be `volatile`.

## Getting started

### Requirements

- `arm-none-eabi-gcc` toolchain
- `make`
- OpenOCD or ST-Link tools for flashing
- ST-Link programmer (or compatible)

### Build and flash

```bash
make all
```
